Quotes library

A private place in the app to save a quote, say who said it, and keep a link or a short note about where it came from.

What I found. The app already has an authenticated top-level navigation layout, typed TanStack Start server functions, and a SQLite/Drizzle schema with committed migrations. Kindle data has its own feature module; Quotes should follow that shape without being coupled to Kindle.

What I recommend

  • Add a Quotes tab and an authenticated /quotes page.
  • Put a small “Add quote” form at the top and show saved quotes beneath it, newest first.
  • Let the same form switch into edit mode. Each saved quote gets Edit and Delete controls.
  • Store each quote in a new quotes table. Do not add tags, search, or archiving in the first pass.
  • Keep database access in a Quotes server module and expose only typed, authenticated server functions to the route.
FieldPurpose
idStable numeric identifier.
textThe quote itself. Required.
attributionWho said or wrote it. Optional.
source_urlOptional web page where you found it.
source_noteOptional plain-language reference, such as a book title, episode, or personal note.
created_atWhen you saved it; determines default order.
updated_atWhen you last edited it.

One thing to decide

Decided: only quote text is required. Attribution, a web link, and a source note are all optional, so you can save something quickly and fill in context later. Saved quotes can be edited. Deletion permanently removes a quote after a clear confirmation; this first version does not add an archive/trash area.

How we will check it

  • Generate the Drizzle SQL migration, review it, and run db:check.
  • Add database-backed tests for creating, editing, deleting, and reading quotes in newest-first order.
  • Run app tests, lint, typecheck, and production build.
  • On the deployed app, add one quote with a URL and one with a source note, then confirm both render correctly.
