# Product

## Register

product

## Users

Andrew uses this private app for personal tools. Each tool should work even when he is new to the subject.

## Product Purpose

Keep useful personal workflows in one quiet, dependable place. A screen succeeds when Andrew knows what to do next without outside instructions.

## Brand Personality

Clear, calm, and practical.

## Anti-references

Avoid dense professional dashboards, unexplained jargon, decorative clutter, and interfaces that assume expert knowledge.

## Design Principles

- Use plain language and define necessary terms.
- Put the next useful action in view.
- Show advanced detail only when it helps the current task.
- Preserve the user's choices and make destructive actions clear.
- Keep tools familiar and consistent across the app.

## Accessibility & Inclusion

Use semantic controls, visible keyboard focus, readable contrast, large touch targets, and reduced-motion support. Never rely on color alone to communicate state.
